# S4c-A1 Injured status (samples)

Cartoon bandage sticker, dizzy stars (with the wind-up fade), the 'shake it off' puff and the text-free 'Injured!' pop-up plate. Enemies only. Overlay sheets match each enemy's own sheets (8 directions). The stars stay at head height and inside the frame (checked by script). The Keeper and Guardians use 2 stars. The wording belongs to S4c-C1. See DELIVERY_NOTE.md and `sprites/injured.json`.

Rebuild from `incoming-art/`:

    python3 status-injured-s4c/source/make_injured.py
    python3 status-injured-s4c/source/make_injured_preview.py
