## Method

Same method as `drafts/planning/L8-sim/l8-sim.ts` and L8-SPEC section 5, so the numbers compare to the published table.

- Whole runs on the real fight rules (`startRun`, `createRunWorld`, the balance bot).
- Typical-artist stats, 60 seeds from seed 1000.
- Bots: kid (style kid, novice skill), newer (smart, typical), careful (smart, sharp), masher (masher, novice).
- Guided and Standard on belts 1–10; Challenge on belts 4–10.
- **PE** uses the Insight ruler (0–60% Power): interpolate cleared (only if the ruler’s max−min > 1), −lost, and −ticks, then average those parts. **Pooled PE** is that function on the summed belts. A **star** (`*`) means the +60% ruler moved health lost by under 1 point on every belt; starred cells were not used to size in the original table. The d9afb0f9 board row dropped the word “unstarred”; it does not change this verdict.
- Limit checked here: one group alone, pooled, ≤ 12, on every bot and difficulty, now including the shield enemy.

**Groups** are the two built Lock families, with the hold on. Stages add no combat numbers.

- group-arm: `counterLock` + `dashOnBlock` 1 (#28)
- group-wrist: `counterLock` + `healOnPerfect` 2 (#33)
- both-groups: all three, reported for context. The Done-when is each group alone.

**Shield rows** use the same whole-run PE. Non-boss spawns are swapped to enemy id `shield`; boss rooms and boss spawns stay so the run can finish. This is not the L8-B2 forced-shield TTK window.

Raw JSON from this run lives with the QA notes (not in this PR). Historical no-hold rows are in `drafts/planning/L8-sim/results/`.

## The 13.4 row

Only one Done-when row is over 12: **group-wrist × careful × challenge × tower, pooled PE 13.4**, not starred. Win 100, rounded lost 6, rounded ticks 240 — the same rounded totals as the no-effect baseline and as the published `#33 heal 2` row on this cell, which was PE 0. Per-belt PE is 7.2 at belt 4 and 0 on belts 5–10. group-arm and both-groups on the same cell are 5.9, matching the published no-hold dash refill / dash+#33 figures.

Unrounded, wrist is only a hair better than baseline (lost 5.95428 vs 5.95593, ticks 239.788 vs 239.818). The +10% power ruler on this cell is slightly *worse* than baseline, and the official interpolator then lerps in the 10–20% bucket, which produces lostPart 14.95 and ticksPart 11.88, average 13.4. The same ticks dip is already why the published `#28` careful-challenge cell reads 5.9.

This is not a real +13.4% power effect, and no retune is proposed. If the cell needs a sizing number, treat it as ~0, in line with heal 2 alone.

## Ambiguities

- L8-SPEC §6 still says “(unstarred)”; the board row at `d9afb0f9` does not. Stars were recorded; they do not change the fail set.
- “Group” is each built Lock family (hold + the rank-2 effect), not hold-only and not the rejected older ARM/WRIST packages from early L8-sim passes.
- Shield rows are a new enemy-swap variant of the same whole-run PE.
- `d9afb0f9` is the work-board SHA that was read; current main is `45f5d6e3`.
- Official `interp` can jump when a ruler step is non-monotonic. That is how 13.4 appeared on a cell whose rounded lost/ticks match a published PE 0 row.
