# server

The Forgotten Server 1.4.2 (protocol 10.98), forked. Upstream details: `UPSTREAM.md`. Our C++ patches: `patches/README.md`.

| Path | What |
|---|---|
| src/, cmake/, CMakeLists.txt | TFS source + Spirebound patches (P1 done) |
| data/ | Spirebound datapack. Engine Lua libraries come from upstream; all game content is ours |
| data/items/ | items.otb + items.xml, **generated** by `tools/build_assets.py --install` (git-ignored) |
| data/world/ | spirebound.otbm + spawns + houses, **generated** by `tools/compile_map.py --install` (git-ignored) |
| schema.sql | TFS database schema (MariaDB 10.11) |
| config.lua, key.pem | **never committed**: rendered by `ops/render_config.sh`, generated by `ops/gen_rsa_key.sh` |

## Build and run (Ubuntu 24.04)

```
sudo apt-get install cmake ninja-build libboost-system-dev libboost-iostreams-dev libboost-filesystem-dev \
  libboost-locale-dev libboost-date-time-dev libluajit-5.1-dev libmariadb-dev libmariadb-dev-compat \
  libpugixml-dev libfmt-dev libcrypto++-dev libgmp-dev mariadb-server gettext-base python3-pil
cmake -S server -B server/build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build server/build
python3 tools/build_assets.py --install && python3 tools/compile_map.py --install
ops/render_config.sh /etc/spirebound/spirebound.env && ops/gen_rsa_key.sh
mysql spirebound < server/schema.sql
cd server && ./build/tfs
```

The whole phase 0 check (build outputs, zero-warning boot, scripted login) is `tools/gate_phase0.sh <env file>`.
