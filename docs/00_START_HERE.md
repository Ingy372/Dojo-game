# Spirebound — start here

Docs live in `/docs`. Every path in these docs is written from the repository root (for example `data/monsters.csv`, `tools/gen_tables.py`, `STATUS.md`).

You are the implementing agent (Claude Cowork or Claude Code). The owner does not map, sprite, script, or compile. The owner plays builds at each phase gate, makes the decisions marked OWNER in `02_LOCKED_DECISIONS.md`, and pays for hosting. Everything else is yours unless `20_HANDOFF.md` assigns it to Grok or a human.

Spirebound is an original-art Open Tibia server inspired by the floating-tower structure of Sword Art Online and the rules of classic Tibia: hunts, loot, skulls, houses, guilds, depots, parties, mages, and paladins. Floors open for the whole world when a raid kills the floor boss. Proof of concept is 5 floors, then a closed beta, then expansion.

## Authority order (when files disagree)

1. `02_LOCKED_DECISIONS.md` — owner intent. Never override.
2. `05_WORLD_RULES.md` — gates, boss rooms, PvP, death, solo-scaled enrage.
3. `14_SECRETS_AND_BROKER.md` and `15_HOUSES_AND_GUILDS.md`.
4. `data/*.csv` — every number. Generated by `tools/gen_tables.py` (secret content from `tools/secrets_src.csv`). Change the generator or source, never the CSV.
5. All other docs.

If a conflict is not resolved by this order, stop and write it under `known_gaps` in `STATUS.md`. Do not guess.

## Operating rules

- One phase at a time. Stop at the gate. Update `STATUS.md` in the format shown there.
- Data-driven: Lua tables and CSV imports. No one-off NPC or monster scripts for anything that fits a table.
- Original names, original map, original sprites. No CipSoft map, dat, spr, or otb content. No Sword Art Online names (characters, bosses, places, items, skills) in anything a player can see.
- Never ask the owner to open an editor. If a tool needs a GUI, replace it with a script (see `03_TECH_STACK.md`).
- If art is missing, use generated placeholders and keep going. Art never blocks a phase gate except phase 8.
- Do not add a sixth path, floor 6, a donation shop, mobile clients, or any system not in these files until the owner writes it into `02_LOCKED_DECISIONS.md` after beta.
- Every number you need is in `data/` or derivable from a formula in these docs. If it is not, add it to the generator and record why in `CHANGELOG.md`.

## What "done" means for the owner

They download one client, log in, pick a path, hunt with friends on floor 1, see a sealed stair, and watch the whole server get a gold message and a bell when a raid kills the floor boss. They never open an editor.
