# Pass 1 — kept, not the pictures to review

These are the first renders of the three Ember Knight shifted-form drafts.

The honey lines were little dots. At phone size they looked like sparks, and the three shields were hard to tell apart. Pass 2 replaces them with solid seams and three clearer shield shapes.

Review `preview/` in the parent folder. These files stay here so the first try was not thrown away.

Blender also wrote automatic `.blend1` backups of these same model files. They matched these copies byte for byte, so they were not stored a second time.
