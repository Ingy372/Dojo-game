## Loudness / duration outliers
- **8-bit files are much hotter:** `sfx_sounds_powerup2.wav` and `sfx_movement_jump1.wav` average about -7.5 dB versus -14 to -24 dB for Kenney. Trim about 8 to 10 dB in the mixer.
- `jingles_SAX03.ogg` is quiet (peak -10.6 dB); the other jingles peak at -1 to -6 dB. Raise it about 6 dB or skip it.
- `sfx_coin_double1.wav` peaks at -11.8 dB, so it is quieter than `coin_single1`.
- Kenney Interface clips sit near 0 dBFS peak (`pluck_001` peaks at -0.0 dB). Leave headroom on the UI bus.
- `click_002.ogg` is only 0.01 s long and may sound like a tick on some devices. `scroll_001.ogg` lasts 1.0 s, which is long for a UI cue.
- Kenney mean levels span about 15 dB (`click_001` -26.4 dB to `confirmation_001` -11.3 dB). Normalize per event group when wiring.
