Draft samples only. Not approved, and not the import set.

| File | Strike |
| --- | --- |

The drawing script is `source/strike_icons.py`. It uses the medallion kit already on main (`incoming-art/icons-slots/source`). Same gold Strike rim, same ink outline, same pine belt as the approved Jumping Spins. Pillow only. No outside art pack. Blender is for the 3D world sprites, not for these flat slot pictures.

Run it from the repo root:

```
python3 incoming-art/icons-strikes/source/strike_icons.py
```
